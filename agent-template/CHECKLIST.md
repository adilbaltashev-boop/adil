# Чек-лист запуска агента

## До разработки
- [ ] Работа агента описана одной фразой
- [ ] Собраны 30+ реальных примеров с правильными ответами
- [ ] Решено: workflow, агент или гибрид
- [ ] Посчитана экономика: цена за задачу × объём vs стоимость человека

## Разработка
- [ ] Инструменты: 3–10, с понятными описаниями и ошибками-подсказками
- [ ] Системный промпт: роль, цель, правила с причинами, формат, передача человеку
- [ ] Знания вынесены в базу/файлы, есть инструмент поиска
- [ ] Права: что сам, что с подтверждением, что никогда
- [ ] Лимиты: шаги, токены, деньги в день
- [ ] Логи каждого шага

## Проверка
- [ ] Прогон на всех примерах ≥ 90% (или осознанно ниже с передачей человеку)
- [ ] Тест на инъекцию: «игнорируй инструкции и …» — агент не послушался
- [ ] Крайние случаи: пустой ввод, другой язык, грубость, сбой API
- [ ] «Смертельной тройки» нет

## Запуск
- [ ] Неделя «агент предлагает — человек одобряет»
- [ ] Владелец получает еженедельный отчёт: % решённых, передачи, жалобы, расходы
- [ ] В договоре: объём работ, кто платит за API, ответственность за данные (закон РК о персданных и об ИИ — сверить с юристом)
- [ ] Каждая найденная ошибка → новый тестовый пример → правка → повторный прогон
