# Тренажёр REST и Kafka

Подпроект для обучения: один файл `index.html`, без зависимостей и сборки. Откройте его в браузере.

Что внутри:
1. **REST** — методы, безопасность и идемпотентность, коды ответов.
2. **Песочница order-service** — сервер `/orders` в памяти страницы: валидация (400), 401, 404, 405 с `Allow`, 409, `Idempotency-Key`, пагинация, ETag (304 и 412).
3. **Kafka** — топик `orders` с партициями, продюсер с ключами, две группы консьюмеров, коммиты, лаг, ребалансировка, повторная доставка, сброс offset'ов.
4. **Связка** — каждый успешный изменяющий REST-запрос публикует событие в топик; outbox и dual write.
5. **Тест** — 9 вопросов с объяснениями.

28 заданий в двух уровнях («Основы» и «Глубже») отмечаются автоматически; у каждого есть подсказка и вывод после выполнения, прогресс хранится в `localStorage` браузера.

Ограничение: это симуляция. Хеш партиций упрощён (в Kafka — murmur2), репликации, retention и транзакций нет. Следующий шаг — настоящая Kafka в Docker (`apache/kafka`, режим KRaft) и те же задания через `kafka-console-producer`, `kafka-console-consumer` и `kafka-consumer-groups`.
