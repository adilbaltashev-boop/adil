# ИИ-помощник для Telegram-канала

Отвечает людям в **комментариях под постами** и в **личке** (через Telegram Business).
Режим по умолчанию — **черновик → ты одобряешь**: бот присылает тебе ответ с кнопками
«✅ Отправить / ✏️ Исправить / ✖️ Пропустить». Сам ничего не публикует, пока ты не включишь `AUTO_REPLY`.

Под каждым ответом стоит пометка «— ИИ-помощник» (закон РК об ИИ требует маркировать сгенерированный контент; сверься с юристом).

## Как устроено
```
комментарий / личка ──► brain.py: один вызов Claude ──► reply / handoff / ignore
                                                        │        │         └─ молча пропустить (спам, эмодзи)
                                                        │        └─ «🙋 Нужен ты» тебе в личку
                                                        └─ черновик тебе с кнопками ──► отправка с пометкой
```
Это workflow, а не агент с циклом: шаги всегда одинаковые (стр. 3 пособия), поэтому дешевле и предсказуемее.
Всё пишется в SQLite (`data/assistant.db`): вход, черновик, твоё решение, токены. `/stats` — отчёт за неделю.

**Безопасность.** Бот читает чужой текст и пишет наружу, поэтому у него **нет доступа к приватным данным** —
третья сторона «смертельной тройки» убрана. Не клади в `knowledge.md` ничего, что нельзя показать любому
комментатору. Чужие сообщения передаются модели в тегах как данные, а не команды.
Личку бот обрабатывает только с твоего Business-подключения; сообщения других ботов игнорирует;
не больше 5 сообщений в час на чат. Повтор одного и того же апдейта не создаст второй ответ.

## Запуск — 7 шагов

1. **Бот.** @BotFather → `/newbot` → получишь токен.
   Там же: `/mybots` → бот → Bot Settings → **Business Mode → Turn on** (нужно для лички).
2. **Комментарии.** Канал → Обсуждение (группа обсуждения) → добавь бота **администратором**.
   Узнать id группы: перешли любое сообщение из группы боту @getidsbot (id начинается с `-100`).
3. **Личка.** Нужен Telegram Premium: Настройки → Telegram для бизнеса → Чат-боты → выбери своего бота,
   дай право отвечать. Без Premium комментарии работают, личка — нет.
4. **Твой id:** напиши @userinfobot.
5. **Настройки:** скопируй `env.example` в `.env` и заполни. Ключ Claude — console.anthropic.com → API Keys.
6. **Знания:** заполни `knowledge.md` — услуги, цены, как записаться, частые вопросы. Чего там нет, бот передаст тебе.
7. **Твой стиль:** экспорт группы обсуждения (Telegram Desktop → ⋮ → Экспорт истории → JSON), затем
   ```bash
   python scripts/import_export.py путь/к/result.json --owner-id ТВОЙ_ID
   ```
   15 твоих ответов уйдут в промпт как образец стиля, остальные — в тесты.

Запуск (Python 3.12+):
```bash
pip install -r requirements.txt
```
```bash
python -m assistant.bot
```
Бот должен работать постоянно — на своём компьютере или на VPS (самый дешёвый хватит).

## Прогон на примерах (до запуска и после каждой правки промпта)
```bash
python ../../agent-template/evals/run_evals.py evals/cases.jsonl --agent assistant.eval_adapter:run
python ../../agent-template/evals/run_evals.py evals/cases_from_export.jsonl --agent assistant.eval_adapter:run
```
`evals/cases.jsonl` — проверки безопасности (инъекции, жалобы, спам). Твои реальные примеры — в
`evals/cases_from_export.jsonl`; поставь им `expect` (где нужен handoff, где ignore, что обязано быть в ответе).
Прогон тратит деньги на API.

## Когда включать автоответ
Неделю работай с черновиками. Каждая твоя правка сохраняется — это новые тестовые примеры.
Когда `/stats` покажет **≥ 90% черновиков отправлено без правок** — поставь `AUTO_REPLY=true`.
Жалобы, возвраты и всё, чего нет в знаниях, бот и тогда передаёт тебе.
