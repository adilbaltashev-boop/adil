# Проект
Мастерская ИИ-агентов. Каждый агент — папка `agents/<имя>/`, создаётся копией `agent-template/`.
Python 3.12. Часовой пояс — Asia/Almaty.

## Как проверять
- `python -m unittest discover -s tests -q` — обязательно перед завершением задачи.
- `python agent-template/evals/run_evals.py <путь к cases.jsonl>` — прогон агента на примерах.

## Правила
- Без набора примеров (30+) агент не считается готовым. Причина: иначе не видно, улучшила правка агента или сломала.
- Секреты только из переменных окружения, никогда в коде, промпте или логах.
- Новые зависимости — только после согласования.
- Если тест падает не из-за твоей правки — скажи, не чини молча.
- Не ослабляй и не удаляй тесты, чтобы они прошли.
