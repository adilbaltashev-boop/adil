## Что освоить в DBeaver

| Действие | Где / клавиши (macOS) |
|---|---|
| Новый SQL-редактор | правый клик по базе → SQL Editor → New SQL script (⌃]) |
| Выполнить один запрос под курсором | ⌘ + Enter |
| Выполнить весь файл как скрипт | ⌥ + X |
| План запроса | ⌘ + ⇧ + E (Explain Execution Plan) |
| Схема по умолчанию | выпадающий список схем в шапке редактора → `credit` |
| ER-диаграмма | правый клик по схеме `credit` → View Diagram |
| Комментарий к таблице/колонке | вкладка Properties у таблицы — комментарии из `COMMENT ON` |
| Выгрузка результата в Excel/CSV | правый клик по результату → Export data |
| Форматирование SQL | ⌘ + ⇧ + F |

Совет: в начале каждого скрипта пиши `SET search_path TO credit;`, тогда не нужен префикс `credit.` перед таблицами.

## Ключевые операторы — шпаргалка

Порядок **написания**: `SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY … LIMIT`.
Порядок **выполнения**: `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`.
Поэтому псевдоним из `SELECT` нельзя использовать в `WHERE`, но можно в `ORDER BY`.

- `WHERE` фильтрует строки до группировки, `HAVING` фильтрует группы после.
- `NULL` сравнивают только через `IS NULL` / `IS NOT NULL`. `= NULL` всегда «не истина».
- `count(*)` считает строки, `count(колонка)` — непустые значения.
- Даты фильтруй диапазоном `>= начало AND < конец`, а не функцией от колонки: так работает индекс.

## Задания

Сначала попробуй сам, потом сверься с решением.

1. Выведи все кредитные продукты по возрастанию ставки.
2. Найди ИП с доходом больше 700 000 ₸, самых богатых сверху.
3. Посчитай заявки в каждом статусе.
4. Для каждого канала подачи (`channel`) выведи число заявок, среднюю, минимальную и максимальную сумму.
5. Выведи заявки за октябрь 2026 года.
6. Посчитай долю отказов (%) по каналам среди заявок, по которым принято решение.
7. Найди клиентов с фамилией на «Ахмет».
8. Сколько клиентов без отчества?
9. Десять крупнейших кредитов.
10. Выдачи 2025 года по месяцам: число кредитов и объём.
11. Клиенты, подавшие больше трёх заявок.
12. Сколько клиентов младше 25 лет на дату песочницы (`sandbox_today()`)?
13. Платежи по каналам: количество и сумма.
14. Раздели клиентов на сегменты по доходу (до 200 тыс., 200–500 тыс., 500 тыс. – 1 млн, от 1 млн) и посчитай каждый.
15. Какие цели кредита встречаются и сколько раз?
